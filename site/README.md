# tidy-one site

The landing page for tidy-one: a static, three-language page (Korean default, English, Simplified Chinese) with no framework and no build server. A small Python script turns one HTML template and three copy files into plain HTML.

```
site/
├── build.py            # renders the template, draws the pixel art, writes dist/
├── i18n/
│   ├── ko.json         # copy, final, used verbatim
│   ├── en.json
│   └── zh.json
├── src/
│   ├── template.html   # one template for all languages ({{ key.path }} placeholders)
│   └── assets/
│       ├── site.css    # Sage Minimal styles
│       ├── site.js     # language memory, menu, hero pixel field, footer game
│       ├── favicon.svg            # generated by build.py
│       ├── og.png                 # generated by build.py (1200 x 630)
│       └── apple-touch-icon.png   # generated by build.py
└── dist/               # build output (safe to delete; build.py recreates it)
    ├── index.html      # ko  (/)
    ├── en/index.html   # en  (/en/)
    ├── zh/index.html   # zh-Hans (/zh/)
    ├── assets/
    ├── robots.txt, sitemap.xml, .nojekyll
```

## Build

Python 3.9+ standard library only.

```sh
python3 site/build.py
```

The script checks that all three copy files have the same keys and that every placeholder in the template resolves. If not, it stops with the missing keys.

Canonical, `hreflang`, `og:url`, `og:image`, the sitemap and `robots.txt` use absolute URLs built from `SITE_BASE_URL`. It defaults to the GitHub Pages project URL, `https://junwonkim07.github.io/tidy-one` (served under the `/tidy-one/` base path). To build for another host, set it (the older name `SITE_URL` still works):

```sh
SITE_BASE_URL=https://tidy-one.example python3 site/build.py
```

Every link inside the pages is relative: assets (`assets/…` or `../assets/…`), the language switcher (`./`, `en/`, `../zh/`), the home link and the stored-language redirect. So the same `dist/` works at `/` on a local server and under `/tidy-one/` on GitHub Pages. `build.py` also writes `dist/.nojekyll` so Pages serves the files as they are.

On a project site, crawlers only read `robots.txt` at the host root (`junwonkim07.github.io/robots.txt`), so the copy in `dist/` matters only with a custom domain. Submit `sitemap.xml` in Search Console instead.

## Preview

```sh
python3 -m http.server 4310 --directory site/dist
# open http://localhost:4310/      (ko)
#      http://localhost:4310/en/   (en)
#      http://localhost:4310/zh/   (zh)
```

To check the GitHub Pages base path, serve a copy from a `tidy-one/` subfolder:

```sh
mkdir -p /tmp/pages/tidy-one && cp -R site/dist/. /tmp/pages/tidy-one/
python3 -m http.server 4311 --directory /tmp/pages
# open http://localhost:4311/tidy-one/, /tidy-one/en/, /tidy-one/zh/
```

## Edit copy

Change the text in `i18n/*.json` and rebuild. Keep the keys identical across the three files. Lists (`works_with.items`, `status.done`, `status.next`) can grow or shrink.

## Deploy to GitHub Pages (later)

The repository has a workflow at `.github/workflows/pages.yml` along these lines. Once the repository is public, pick **Settings → Pages → Source: GitHub Actions**:

```yaml
name: Pages
on:
  push:
    branches: [main]
    paths: ["site/**"]
  workflow_dispatch:
permissions:
  contents: read
  pages: write
  id-token: write
concurrency:
  group: pages
  cancel-in-progress: true
jobs:
  deploy:
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"
      - run: python3 site/build.py
        env:
          SITE_BASE_URL: https://junwonkim07.github.io/tidy-one
      - uses: actions/configure-pages@v5
      - uses: actions/upload-pages-artifact@v3
        with:
          path: site/dist
      - id: deployment
        uses: actions/deploy-pages@v4
```

With a custom domain, set `SITE_BASE_URL` to that domain and add a `CNAME` file to `src/assets/`, or set the domain in the Pages settings.

## How it behaves

- **Languages.** The switcher (KO / EN / 中文) links the three static pages. A click stores the choice in `localStorage` (`tidy-one:lang`, wrapped in try/catch). On `/`, a stored `en` or `zh` choice sends the visitor to that page. On a first visit to `/` from a browser whose first language isn't Korean, a small bar suggests English or Chinese. It never redirects on its own.
- **Hero pixel field.** A `<canvas>` draws pixels that hang from the hairline in loose clouds, slightly off the grid. Scrolling tidies them: each pixel travels to its own cell and clicks into place, filling 3 x 3 tiles (the mark's pattern) sorted from slate to mist. The tiles fill the whole field with an even margin, and the "scroll to tidy" hint fades out as they settle. Only whole cells are drawn. After load or a scroll the scattered pixels drift slowly (about 10 fps) for under 5 seconds, then the loop sleeps until the next scroll; it also stops when the canvas is off screen. With `prefers-reduced-motion` it draws the tidy end state once and ignores scrolling.
- **Footer game.** Twelve pixel buttons are scattered in a field. A click or tap, or Enter/Space on a focused pixel, sends it to its own slot in a 4 x 3 grid. Each button has a localized name ("Move pixel 4 to its slot"), and the tab order follows the field from top to bottom. A counter tracks progress. Placing the last pixel hides the empty field, centres the board, announces the done message through a live region and focuses a button to scatter again (the game group holds focus for the half second before that button appears). Light pieces have a deep-sage edge, so every piece stands out from the paper at 3:1 or more.
- **Motion.** Nothing loops forever: the badge dot blinks twice, the scroll-hint arrow nudges twice, and in "How it works" a packet runs once down each wire, in order, whenever the steps come into view. All of it stops within 5 seconds and is off with `prefers-reduced-motion`.
- **Art.** `build.py` holds the pixel bitmaps: icons, the mark, the how-it-works nodes and a 5 x 9 font for the OG wordmark. It renders them as inline SVG and writes `favicon.svg`, `og.png` and `apple-touch-icon.png` with a tiny PNG encoder. Output is deterministic, so rebuilding doesn't change these files.

## Design notes

- Palette "Sage Minimal": `#CAD2C5` mist, `#84A98C` sage, `#52796F` deep sage, `#354F52` pine, `#2F3E46` slate. Background `#F8F9F7`, mist at about 14% on white. Text is slate or pine. Small labels are deep sage, used only on the light background (4.6:1). Mist and sage are used only for pixels, fills and lines, never for text on light backgrounds.
- Type: Inter Tight for Latin display and text, Pretendard (jsDelivr, dynamic subset: only the unicode-range slices the page uses are fetched) for Korean, the system CJK fonts (PingFang SC, Microsoft YaHei, Noto Sans CJK SC) for Chinese, JetBrains Mono for the small uppercase labels. Font stylesheets load without blocking first paint (`rel=preload` switched to a stylesheet on load, with a `<noscript>` fallback) and use `font-display: swap`.
- Line breaks: Korean uses `word-break: keep-all`; Chinese uses normal CJK breaking with `line-break: strict`, so 。 and ， never start a line. In the copy, `|` marks a phrase that moves to the next line as a whole (an inline block, so it wraps inside only when it alone is wider than the line, e.g. with enlarged text spacing) and `||` a sentence that starts a new line when it doesn't fit beside the previous one (`build.py` turns them into `<span class="ph">` and `<span class="sen">`). A heading's final full-width stop is set half width with the `halt` font feature. Headings use `text-wrap: balance`; nothing is justified.
- Buttons, badges and the language pills have pixel-stepped corners (`clip-path` on a pseudo-element, so focus outlines are not clipped).
- No JavaScript libraries. The page is about 30 KB of HTML plus 30 KB of CSS and 21 KB of JS before compression. Web fonts add roughly 75 KB on `/en/` and `/zh/` (Inter Tight and JetBrains Mono, Latin only) and about 0.5 MB more on the Korean page (Pretendard slices).
- Product names in "Works with" are plain text. tidy-one is not affiliated with them.
